# Aplicación móvil

Android nativo con Kotlin. Consume la API REST del backend.

Alcance previsto: consulta de catálogo con filtros, lectura de códigos de
barras y QR con la cámara, generación de cotizaciones, registro de
pedidos y consulta sin conexión de los datos ya sincronizados.

Versión mínima: Android 10, nivel de API 29.

Pendiente de iniciar. Corresponde al Sprint 6 del plan de trabajo.
