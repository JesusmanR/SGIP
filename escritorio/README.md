# Módulo administrativo de escritorio

Java Swing. Componente heredado de la fase previa del proyecto, que se
conserva sin reescritura.

Tras la migración a la arquitectura de tres componentes deja de acceder
directamente a la base de datos y pasa a consumir la API REST, igual que
la aplicación móvil.

Lo construido y reutilizable: lógica de dominio con setenta y nueve
pruebas unitarias, pantalla de acceso, derivación de contraseñas y
auditoría de accesos.
